# Y-29 H5

375px 基准的移动端影视站，参考 safilm69.com 移动页面，沿用 Y-29 的万象标识、深灰背景 #17181b 和橙色 #ff7231。

运行 `npm run dev`，访问 http://localhost:5174 。`dist/` 可作为静态站点目录，深层路由需要回退到 index.html。运行 `npm run check` 执行回归检查。

已实现首页轮播、横滑推荐、三列片库、主题、分类筛选、搜索、详情选集、排行榜、个人收藏和历史记录。布局在桌面最大480px居中，手机随视口适配。主样式位于 dist/h5.css。

图片与457部影片来自 Y-29 的本地快照，不会自动同步参考站。没有复制第三方广告弹窗，未接入账号、付费或远程视频服务。当前属于界面还原和本地交互实现，未进行逐像素自动差异比对或 Lighthouse 测试。
